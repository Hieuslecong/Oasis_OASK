STATIC SOURCE HASHES ARE INTENTIONALLY NOT AUTHORITATIVE.

The source changes during repair work, so a committed hash list becomes stale as
soon as the implementation changes. Generate the exact inventory for the code
you are about to run instead:

python scripts/write_source_hashes.py --out /path/to/run/source_hashes.txt

Store that generated file together with run_metadata.json, effective_config.json,
manifest SHA256, student-init SHA256 and critic-checkpoint SHA256.
